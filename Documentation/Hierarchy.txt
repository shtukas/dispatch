
Hierarchy

Each regular item contains the uuid of its parent in `parentuuid`.

Vitual items that are children of a parent, may possibly not have it, but Hierarchy::children(parentuuid) returns the right children

All children ordering types
    "ordered-by-rt",
    "ordered-by-gps-strict-sequence",
    "ordered-by-gps-(1/2^n)-sequence",
    "distribution"

ordering directives

{
    "type" => "ordered-by-rt"
}
{
    "type" => "ordered-by-gps-strict-sequence"
}
{
    "type" => "ordered-by-gps-(1/2^n)-sequence"
}
{
    "type" => "distribution"
}

When the parent ordering directive is `distribution` then some (but not all) children have a ratio, stored at 
"ceb929a4-605c-407c-9986-b44b835ac4df:#{uuid}"
